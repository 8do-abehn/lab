### Major Issues & Lessons Learned

**1. GPO Scope Matters - Admin Rename Disaster**
- `POL-Workstations-Security` was linked to domain root
- "Rename administrator account" setting renamed DOMAIN Administrator to LabAdmin
- On DCs, the "local" admin IS the domain admin
- **Lesson:** Link workstation-specific GPOs to Workstations OU, not domain root

**2. Security Baselines Break Things**
- Microsoft Security Baseline restricted "Allow log on through Remote Desktop Services" to only Administrators and Remote Desktop Users
- Regular domain users couldn't RDP
- **Fix:** Override GPO + explicit group memberships

**3. GPO Link Order**
- Lower number = processed LAST = wins
- Baseline at position 1 was overwriting our fixes
- Had to move override GPO to position 1

**4. Group Memberships Required for RDP**
Even with "Users" in SeRemoteInteractiveLogonRight:
- Added `Domain Users` → `Remote Desktop Users` local group
- Added `SG-Tier2-WorkstationAdmins` → `Administrators` local group

**5. Local Admin Disabled by Baseline**
- Security baseline disables built-in local Administrator
- Need LAPS password + enable via GPO if needed
